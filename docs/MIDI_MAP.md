# Default MIDI Map

General MIDI percussion defaults on MIDI channel 10.

| Role | MIDI note | GM name |
|---|---:|---|
| Kick | 36 | Bass Drum 1 |
| Snare | 38 | Acoustic Snare |
| Hi-hat closed | 42 | Closed Hi-Hat |
| Hi-hat pedal | 44 | Pedal Hi-Hat |
| Hi-hat open | 46 | Open Hi-Hat |
| Tom 1 | 48 | Hi-Mid Tom |
| Tom 2 | 45 | Low Tom |
| Crash | 49 | Crash Cymbal 1 |
| Ride | 51 | Ride Cymbal 1 |

The firmware should make these configurable rather than treating them as permanent hardware identities.
